# 🍕 Pizza Corp — Аналіз продажів та Стратегія зростання

Проєкт із комплексного аналізу даних продажів мережі піцерій **Pizza Corp** за рік. Мета проєкту — виявити операційні вузькі місця, оптимізувати меню, сформувати рекомендації щодо штатного розкладу та підвищити загальну виручку компанії.

---

## 📌 Опис проєкту

У межах дослідження було проаналізовано масив із **21 350 замовлень** (близько **50 000 проданих піц**) із загальним виторгом **$817.8K**. 

**Основні складові проєкту:**
* **Презентація (HTML):** Інтерактивна презентація з 14 слайдів із графіками, адаптивним верстанням та вбудованим дашбордом.
* **Інтерактивний дашборд Tableau:** Панель із 3-х вкладок для глибокої фільтрації та аналізу показників у реальному часі.
* **Доповідь (Скрипт спікера):** Повний текст виступу для захисту проєкту перед керівництвом.

## 💡 Короткі відповіді на бізнес-питання

* **Який середній чек та обсяг замовлення?**  
  Середній чек складає **$38.31**, а середній розмір замовлення — **2.3 піци**.

* **Які піци та категорії генерують найбільшу виручку?**  
  Категорія **Classic** є лідером за обсягом продажів, а **Chicken** — за маржинальністю. Найпопулярніші піци: *The Thai Chicken Pizza* ($43.4K) та *The Barbecue Chicken Pizza*.

* **Які позиції є аутсайдерами та потребують ротації?**  
  Найменш популярна позиція — *The Brie Carre Pizza* ($11.6K). Також низьку частку виручки показує категорія **Vegetable**.

* **Який розмір піци найпопулярніший?**  
  Розмір **Large (L)** генерує **45.8%** усієї виручки ($375K), на другому місці **Medium (M)** — **30.7%**.

* **Коли спостерігаються піки завантаження?**  
  Чітко виражені два піки: **обідній (12:00–13:00)** та **вечірній (17:00–19:00)**, з максимумом у п'ятницю та суботу.

* **Які ключові рекомендації для бізнесу?**  
  1. Оптимізувати графіки змін кухні та кур'єрів під пікові години.  
  2. Вивести з меню *Brie Carre Pizza* та переглянути категорію *Vegetable*.  
  3. Впровадити комбо-сети на базі ходових розмірів L та M для підняття середнього чека на 10–15%.
